# Dulani De Silva – personal website

Open `index.html` in a text editor. Search for `EDIT` to find every place you may want to change.

## Folder layout
- `index.html` – the whole page (text, styles and animations are all in this one file)
- `assets/img/` – photos and preview images
- `assets/video/` – compressed videos
- `assets/docs/` – CV, papers, reports, design PDFs and certificates

## Put it online with GitHub Pages
1. Create a new public repository named exactly `DulaniDeSilva.github.io`.
2. Upload everything in this folder (index.html, README.md and the assets folder).
3. Go to Settings → Pages → Source: "Deploy from a branch", branch `main`, folder `/ (root)`.
4. Wait 1–2 minutes, then open https://dulanidesilva.github.io

## Updating the CV
Replace `assets/docs/Dulani_De_Silva_CV.pdf` with the new file (keep the same name).
